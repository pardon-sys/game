# 骑士篇之后：剧情与关卡设计稿

> 第二轮确认后的定稿。✅ = 已确认；🛠 = 已实现。还没定的细节在最后「之后再确认」里。
> 规矩照旧：游戏内文字全中文；每章挠痒剧情**一样重**（完整四幕 + 至少一次魔力释放后被挠 + 战败 CG）；粉色公主主写脚，蓝色公主主写大腿；CG 只在被挠时赤脚。

## 1. 第一章：吵架与反省 🛠（`--penance-only`；鼠鼠装的精灵 / 立绘造型留到第二章）

### 1.1 开场 ✅
- 骑士被抬进保卫队营地的医务帐篷，一直没醒。半枚徽章在蓝色公主手里。
- 粉色公主要回地面查清自己是谁、王国为什么会亡；保卫队队长说什么都不让（理由含糊，说到一半就停）。
- 蓝色公主几次想插嘴（「……那个」「……我觉得」），每次都被两边的声音盖过去。
- 队长：「……关起来。让她好好反省。」

### 1.2 反省牢房 ✅（6 件**全部**玩过才能推进）
每件按 E 调查触发一段长小剧场（有失控一、失控二、至少一次魔力释放后被挠）；结尾她都嘴硬一句「我才不会认错」。

| # | 道具 | 要点 | 部位 |
|---|---|---|---|
| 1 | 反省足枷凳 | 凳子会「听」：每说一句嘴硬的话，枷下的刷子就快一档 | 脚心、脚趾缝 |
| 2 | 痒痒床头人偶 | 抱着睡，布偶的手偷偷挠腰和膝窝；背后绣着「两个手拉手的小人」（线索） | 腰、膝窝、大腿 |
| 3 | 功能拘束挠痒床（章末大段 + CG） | 四档：羽毛扫脚心 → 翻身板刷大腿后侧 → 腰侧软刷 → 全开；想按「停止」按成了「加速」 | 脚心 → 大腿后侧 → 腰 |
| 4 | 痒痒浴桶 | 「洗洗脑子」：桶底软刷和泡泡轮流刷脚底、腿根 | 脚底、腿根 |
| 5 | 猫咪看守 | 队长的橘猫，哄它叼钥匙反被舔脚心、尾巴扫腿（第二章会追穿鼠鼠服装的她） | 脚心、小腿 |
| 6 | 队长的旧战利品箱 | 试穿三件旧装备（见下），箱底一张旧照片：年轻的队长抱着一个小女孩，背景是王宫大门（线索） | 视装备 |

**战利品箱三件** ✅：
- **笑笑袖套**：内侧缝着软毛的长袖套，一抬手就蹭腋窝和腰侧，越想脱越得张开手臂，越痒。队长当年从「笑声小偷」那里收来的。
- **会笑的袜子**：穿上以后袜子自己咯咯笑，袜底的线头在脚心和趾缝里蹭来蹭去；尺码「二十二码半」（呼应裁缝的线索）。
- **握握手短裤**：旧的潜行短裤，内层缝着十几只小布手，一起挠大腿根和屁股，她越夹紧腿小手越勤快；内侧一行褪色小字「给小不点——等你长大了再穿」（线索）。

### 1.3 墙缝里的挠脚鼠 ✅
- 放过它（看过 `prison_rat`）：「又是你！上次的谢礼还满意吗？」；没放过：「哼，上次害我被关了三天……」
- 报酬：让它住在身上——裤子 / 鞋子被强制换成**鼠鼠短裤 + 鼠爪鞋**，钻进墙缝。

## 2. 鼠鼠服装 ✅

- 灰色毛绒鼠鼠短裤（会动的尾巴）+ 露脚趾的鼠爪拖鞋；挠脚鼠住在短裤里。诅咒装备，出了鼠洞才能脱。
- ✅ **偶尔暴击**：每隔 8~15 秒（随机）挠脚鼠乱窜一次——金色「暴击」字 + 暴击音效，闷笑小涨、魔力疲倦大涨。
- ✅ **吸引小范围的怪**：身上的鼠味把附近一小圈的怪引过来。
- ✅ **攻击 −20%**（腿被挠得发软）。
- 精灵图 / 立绘的鼠鼠装造型：第二章做。

## 3. 第二章：鼠洞（等距狭长通道）🛠（鼠鼠装的立绘 17 张 + 行走 / 魔法图都换；章末不脱）

- 狭长、拐弯多、有高低差，一人宽，镜头拉近。
- 三段挠脚鼠剧情 ✅ **纯小剧场**，走到位置自动触发：
  1. **大腿根**：趴着爬过低矮的缝，挠脚鼠在大腿根来回挠，一动就卡住；
  2. **脚心**：脚卡在窄缝里，挠脚鼠挨个舔趾缝找「哪个缝里面包香味最浓」，缝外守卫走过，要憋住；
  3. **上下窜**：竖井往上爬，挠脚鼠从脚心窜到腰又窜回去；魔力释放，笑着滚出井口（本章四幕 + 战败 CG）。
- 通道里的机关 ✅：
  - **滴水管**：滴到脚背上惊动挠脚鼠，暴击一次；
  - **猫咪追逐**：第一章的橘猫追进通道，跑慢了被舔脚心；
  - **老鼠窝**：一群小老鼠想认她当老大，围着鼠爪鞋转圈蹭脚。

## 4. 第三章：汇合与废弃水道

### 4.1 汇合 ✅（🛠 开场已做：`floor_06_waterway_exit` 互相调侃裤子的小剧场；蓝色公主视角那一段还没做）
- 先补一段蓝色公主视角（可操控，短）：她从派对主人那里问到「地牢的鼠洞通向废弃水道」，又从营地拿回了粉色公主的鞋。
- 出口见面：蓝色公主看了很久，「……很合适」。挠脚鼠告别，鼠鼠服装脱下、换回原装。

### 4.2 废弃水道（等距）✅ 换成新的一批　🛠（两人同行 + 水位 / 泡泡 / 小鱼 / 黑泥 + 水闸守门人）
**陷阱**
- **吐泡泡的狮子头**：墙上的狮子头出水口隔一会儿吐一串大泡泡，泡泡把人裹住飘起来，在泡里被小泡泡挠脚底；另一个人要来戳破。
- **闸门轮盘**：两人一起转轮盘开闸，转的时候脚底下的格栅冒出软刷；一停手闸门就落回去。
- **浮木桥**：水上一排浮木，踩上去会翻，木头底下长满水草，翻过来就扫脚底。

**怪物**
- **小鱼群**：从浅水里窜出来，绕着脚踝啃脚趾（「去角质」），站在水里越久鱼越多。
- **黑泥小人**：从水底的泥里冒出来，把泥巴抹在脚底、趾缝里慢慢蹭；踩进清水里洗掉才停。
- 再加现有的怪：泡泡鱼（`bubble_fish`）、螃蟹（`crab`）、青蛙（`frog`）、藤壶（`barnacle`）、章鱼（`octopus`）等，按水道主题挑。

章末：两人被水道深处的「笑声水闸」困住，轮流被挠、互相吐槽；战败 CG。

## 5. 第四章：被遗弃的旧王宫

### 5.1 九张连通的大地图 ✅
所有地图**连在一起、可以来回切换**（门 / 楼梯 / 密道），每张都比之前的地图大（约 60×40 格以上）。隧道与密室把各张图串起来，打开以后可以抄近路。

```
                      [钟楼]
                         │ 旋转楼梯
 [骑士训练场]──回廊──[王座间]──大门──[衣帽间]
       │                 │               │
       │              正厅楼梯          侧门
       │                 │               │
 [图书馆]──书架后──[仆人回廊]──配膳口──[厨房]
       │                 │               │
       └──────[隧道与密室]（壁炉 / 画后 / 书架后，各图都有入口）
                         │
                     [旧浴场]（水道接进来的入口）
```

| 地图 | 玩法 / 挠痒机制 | 怪物 / 陷阱 |
|---|---|---|
| **旧浴场**（入口） | 冒泡的大理石浴池，雕像的手里握着刷子；蒸汽里看不清，跟着笑声找路 | 雕像手、肥皂泡、湿毛巾怪 |
| **仆人回廊** | 潜入：拿掸子的人偶女仆轮流巡逻，被发现就按在地上「打扫」脚底 | 人偶女仆（掸子 / 刷子 / 羽毛）、会动的扫帚 |
| **厨房** | 糕点师人偶「试吃」，往脚底抹奶油让小老鼠舔；冰窖滑道 | 糕点人偶、老鼠群 |
| **图书馆** | 书架间潜入，抽书时书架里伸出手；王国的历史书残页；忍住不笑才能读完一页 | 书虫、会飞的羽毛笔 |
| **衣帽间** | 女王的旧礼服自己动起来给人「量尺寸」，软尺绕着腰和腿根转；能换上旧王宫的装备 | 礼服人台、软尺、针线包 |
| **骑士训练场** | 稻草人和木人桩会反击（挠痒）；屋里有骑士年轻时的痕迹（呼应昏迷的骑士） | 稻草人、木人桩、训练羽毛剑 |
| **钟楼** | 爬楼梯 + 钟摆；钟每敲一下，全楼的羽毛机关动一次（呼应「钟楼上一个殿下」） | 钟摆羽毛、乌鸦 |
| **隧道与密室** | 串起各图的密道网：壁炉、画后、书架后都是入口，里面有机关和宝箱；开了可以抄近路 | 密道机关、宝箱怪（`mimic`） |
| **王座间**（Boss） | 封笑的女王画像（见下） | 画像小手、小画像 |

### 5.2 王座间 Boss：封笑的女王画像 ✅（A+B+C+D 全要）
- **拉进画里**：画框伸出手把一人拉进画里（画中小关卡，画笔在她身上画画 = 挠），另一人在外面打画框救她；
- **颜料泼洒**：地上泼出颜料圈，踩进去脚底沾颜料、被画笔追着刷；
- **画像分身**：墙上的小画像也活过来伸手，先打掉小画像，大画像才露出破绽；
- **两人各释放一次**：笑声被收进画里，满了就各魔力释放一次，释放的魔力把画布烧出缺口（破绽）。
- 战败小剧场 + CG：两人在画框前被画中的手挠。

### 5.3 画像的胡话 ✅（战斗中每破一层说一句，不揭露身份）
越胡言乱语越好，有的完全不相关，有的暗暗沾一点边：
1. 「今天的汤是蓝色的。蓝色的汤不能用勺子喝，要用耳朵听。」
2. 「左边的鞋子比右边的鞋子早出生三天，所以它总是先走。」
3. 「我数过天花板上的星星，一共有十三颗半。那半颗被谁借走了？」
4. 「摇篮在唱歌，歌在找摇篮。……它们说好了，下雨的时候见面。」
5. 「不要相信生日蛋糕。蛋糕上的蜡烛，都是别人的名字。」
6. 「钟敲了十三下以后，所有的猫都会忘记自己是猫。」
7. 「二十二码半的袜子，是给云穿的。云的脚很怕痒，所以一直在跑。」
8. 「半个月亮掉进了井里，另外半个还在天上找它。」
最后画布暗下去，只剩一句：「……嘘。画框后面，有人在睡觉。」
