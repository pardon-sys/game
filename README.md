# 公主地牢冒险

Godot 4.7 · 2D 俯视角像素游戏。粉发蓝眼、头戴金色小皇冠的公主被关进地牢，需要一路解谜、战斗逃出去。

## 操作

| 按键 | 手柄 | 作用 |
| --- | --- | --- |
| WASD / 方向键 | 左摇杆 / 十字键 | 8 方向移动 |
| E | A | 交互（开箱、开门、拉杆、点火把、读石碑/信）/ 推进对话 |
| J / 鼠标左键 | X | 挥动权杖攻击（可打碎木桶、武器架，砍断藤蔓） |
| L / 鼠标右键（按住） | LB | 星光爆发：按住吟唱、松开释放（第三层学会） |
| K / Shift | B / RB | 冲刺（短暂无敌，可穿过尖刺、躲开挠痒） |
| Q | Y | 使用 Q 键绑定的物品（默认薄荷糖：闷笑值 -27%） |
| R | Select | 使用 R 键绑定的物品（默认清心花露：清除全部疲倦印记，Boss 掉落） |
| Tab / I | L3 | 打开背包（第四层储藏室获得；打开时暂停）：查看物品、改 Q / R 绑定、查看状态 |
| Esc | Start | 暂停菜单（继续 / 重新开始 / 退出） |

## 关卡流程

- **第一层**：牢房（拉杆开牢门）→ 火把走廊（点亮火把）→ 守卫室（史莱姆、铜钥匙宝箱；旁边的**兵器库**有武器架和心）→ 储藏室（木桶）→ 书房（骑士的情书、拉杆开铁栅；点亮角落的火把会照出**暗墙**，推开是秘密储物间）→ 尖刺走廊（冲刺穿越，铜锁门）→ 宝库（金钥匙）→ 金锁大门 → 出口楼梯。走廊南侧还有**拉杆谜题间**（先拉外面的，再拉里面的）。
- **第二层**：落脚点 → 蝙蝠巢穴（羽毛蝙蝠、痒痒粉喷口；东边**喷口回廊**通往**蛛丝幽灵房**）→ 幽灵长廊（点火把让痒痒幽灵显形）→ 蜘蛛窝（吐丝减速、多足连挠）→ 机关走廊（旋转羽毛刷、压力板 + 机关手；北侧**休息室**）→ 巨魔大厅（小 Boss 挠痒巨魔，掉落金钥匙）→ 出口楼梯。
- **第三层·痒痒工坊**：落脚点（学会星光爆发，拿小精灵练手）→ 鼠窝（挠脚鼠 + 藤蔓）→ 藤蔓迷道 → 蟹池（钳钳蟹 + 传送带）→ 传送带工坊（西侧可选的**组合试炼间**）→ 风洞走廊（风扇把人吹进粉雾和刷子，东头拉杆关风扇；东侧宝物间里有一只宝箱怪）→ 史莱姆与精灵厅 → 触手怪大厅（Boss）→ 出口楼梯（第三章完）。
- **第四层·魔力回廊**（更难：检查点只有 4 个，每段强制段都对应组合技）：落脚点（石碑讲暴击、魔力疲倦、疲倦爆发、三重组合）→ **储藏室**（宝箱里是冒险背包）→ 水母池 → 诅咒符文走廊 → 泡泡水道（中间只有一条黏黏毛毯路）→ 足枷长廊（毛毯、整宽足枷台、符文、墙上羽毛臂，出口一对幽灵手套）→ **刑台广场**（战斗房：足枷台阵 + 老鼠、螃蟹、蜘蛛、史莱姆、小精灵、手套）→ 刺猬滚道（整高毛毯 + 顶墙羽毛臂，凹槽可躲；南边**诅咒回廊**通往可选的**手套展厅**战斗房）→ 图腾大厅（战斗房）→ 魔力水母女王大厅（Boss）→ 出口楼梯（第四章完）。

## 闷笑值

怪物除了攻击（扣血），还会**挠痒**（累积闷笑值，HUD 心形下方的粉色条）。史莱姆优先选择挠痒：概率75%，冷却0.6秒；普通攻击概率25%，冷却1.2秒。

阶段和恢复量都按**上限的百分比**算（上限现在是 150，以后提高上限只改 `LaughMeter.max_value`）；怪物的挠痒量是固定值，所以上限越高越耐挠。HUD 两条状态条右边显示百分比。

- 超过 35%：移动变慢，时不时发笑
- 超过 55%：失控状态1，无法行动，持续大笑；**连按 J / E 挣扎**（每次 -2%）
- 超过 70%：失控状态2，行动限制相同；降回 70% 以下切回状态1
- 满 100%：笑到脱力，扣半颗心，回落到 70%
- 2 秒没有被攻击后每秒下降 6.7%；薄荷糖立即 -27%；骑士帮忙 -17%
- 被抓住（巨魔、机关手）：不能行动，连按 J / E 挣脱，同时降低闷笑值；挣脱后巨魔会僵直一会儿
- 第二层的怪物更爱挠痒：蝙蝠 90%、幽灵 100%、蜘蛛与巨魔 85%；挠痒时有合成的果冻"啵叽"声
- 第三层：挠脚鼠 90%（公主动不了时挠痒加倍）、钳钳蟹 85%（夹住定身 1 秒）、分裂史莱姆 85%、宝箱怪 90%、小精灵群 100%、触手怪 90%
- 第四层：魔力水母（疲倦 ×3，被打散留水液）、泡泡鱼（泡泡牢笼，连按 5 次戳破）、幽灵手套（成对，两只凑齐必暴击 + 搭档补挠，只挠不打）、刷刷刺猬（同行 / 同列时滚过来，必暴击 + 击退，滚动时剑打不动，撞墙会晕）、魔力水母女王（召唤水母、留水液、半血后魔力雨）

## 特殊挠痒（暴击）

怪物的每次挠痒（包括抓住后的持续挠痒）都可能是**特殊挠痒**：闷笑值 ×2，魔力疲倦 ×2（按暴击后的量再乘），播放水里果冻抖动的升调音效，公主头上跳金色「暴击！」、镜头轻震，公主说该怪物专属的暴击台词（`princess_reactions.json` 各来源的 `special`）。

- 暴击率：普通怪 12%、Boss 20%（水母 25%、水母女王 35%），在 `data/monsters/*.tres` 的 `special_chance` 调；「狂热」增益 +20%
- 必暴击：幽灵手套成对时、刷刷刺猬滚中时、足枷台超时的最后一下、组合技的「下次必暴击」

## 魔力疲倦

HUD 闷笑条下方紫色的「魔力」条（上限 500，刻度 40% / 60% / 80%，超过 90% 闪烁并提醒）。

- 被挠痒时积累：挠痒量的一半；暴击时为两倍；魔力水母的挠痒再 ×3；诅咒符文（+4%）、魔力雨（每秒 +0.6%）、部分组合技（+2% ~ +10%）按百分比直接加
- **不会消散**：不随时间下降，复活不清零，跨层保留（重新开始游戏才清零）
- 闷笑积累加成（先缓后升）：20% → +1%、40% → +5%、60% → +10%、80% → +30%、100% → +50%
- **疲倦爆发**：满 500 自动释放一次星光爆发（战损释放姿势，满蓄力的一半：半径 72、伤害 2，不僵直），疲倦清零；原地留下**疲倦水液**（30 秒，怪物踩进去获得「力量」）；公主获得一层永久的**疲倦印记**（闷笑积累 +1%）。爆发台词在 `data/princess_fatigue.json`
- **清心花露**（默认 R 键）：清除全部疲倦印记；只有 Boss 掉落（挠痒巨魔、痒痒触手怪、魔力水母女王）

## 增益 / 减益

所有角色（`Actor`）都能带状态，定义在 `data/buffs.json`。公主的状态显示在 HUD 心形右边（限时的快结束时闪烁，印记显示层数）；怪物有增益时头顶有小图标。

| 状态 | 效果 | 来源 |
|---|---|---|
| 力量（增益） | 挠痒冷却 ×0.6 | 疲倦水液、组合技 |
| 狂热（增益） | 暴击率 +20%，挠痒冷却 ×0.8 | 狂热图腾光环、精灵起哄 |
| 易痒诅咒 | 闷笑积累 +30% | 诅咒符文、组合技 |
| 黏黏 | 移动速度 ×0.4 | 黏黏毛毯、组合技 |
| 封魔 | 不能吟唱 | 无形蛛网 |
| 疲倦印记（永久，可叠层） | 每层闷笑积累 +1% | 疲倦爆发 |
| 抬起 | 被举到半空，动不了、挣扎无效、一直被挠 | 三来源组合 |
| 晕头转向 | 方向键颠倒 | 三来源组合 |
| 全场暴击 | 受到的每一下挠痒都算暴击 | 三来源组合 |

第四层陷阱：**狂热图腾**（光环内怪物狂热；剑敲三下或任意档星光爆发打碎）、**诅咒符文**（易痒 10 秒 + 疲倦 4%）、**足枷台**（锁住 3 秒，连按 6 次挣脱，超时最后一下必暴击）、**黏黏毛毯**（多格；站着不动 1 秒被黏住）、**伸缩羽毛臂**（墙面，红灯预警后横扫前方两格，定身 + 挠痒 8）。传送带比以前更快（默认 70）。

## 笑倒 CG

被挠到笑倒时，不会直接复活，而是先播一段笑倒 CG：画面切到一个小舞台，挠倒公主的那只怪物登场继续挠，配合对话、立绘切换和镜头，最后在检查点醒来。

- **算笑倒**：闷笑值满把最后一点血笑没；或者倒下时正在失控（闷笑值 >55%）、正被抓住、2 秒内刚被挠过（最后一下是普通攻击也算）。不在挠痒状态时被打死不播 CG，照旧复活。
- 16 种怪物各有一段专属 CG（按最后挠她的怪物选；来源不明时按打倒她的怪物），陷阱致死播通用 CG。
- 怪物 CG 分三幕：失控 1 立绘 → 失控 2 立绘 → **CG 图**（剧情最多）。有两张 CG 图的怪物（泡泡鱼、魔力水母女王）多一幕：第三幕第一张图、第四幕第二张图。CG 图阶段立绘框变成对话框上方的横版大框（保持原图比例），并随挠痒抖动；右边的小舞台继续演。
- 每次笑倒都会播；看过的 CG 画面角落会提示「Esc 跳过」，第一次看不能跳过。
- 所有 CG 写在一个文件 `data/cgs.json` 里（对话、演员、演绎指令、立绘都按步骤写），格式说明在文件开头和架构文档里。
- **立绘接口**：前两幕的 CG 立绘现在用失控 1 / 失控 2 占位，正式素材按 id 命名放进 `assets/cg/portraits/`（如 `slime_1.png`）就会自动替换，见该目录的 README。
- **CG 图**：手绘原图放在 `assets/generated/CG/<来源键>.png`（两张图时命名 `<来源键>_1.png` / `<来源键>_2.png`，扩展名大小写都行），运行 `python tools/art/import_cg.py [--preview]` 像素化成 `assets/cg/portraits/<来源键>_3.png`（第二张为 `_4.png`；保持比例、高 360 = 显示 180 的 2 倍密度）。然后运行 `python tools/build/gen_cgs.py` 重新生成 `data/cgs.json`：CG 图存在时自动用横版大框，台词也在这个脚本里改。

## 关卡设计：躲不开的陷阱配合

每层都有几段"强制遭遇"，参考第三层风洞走廊（风扇把人吹进痒痒粉和旋转刷）的做法，让陷阱和怪物的配合绕不过去：

- **强制位移**：风扇风道、传送带铺满整条通道，把人送进喷口 / 旋转刷 / 机关手 / 怪物堆；关掉它们的拉杆放在危险区的另一侧。
- **窄道铺满陷阱**：羽毛陷阱、藤蔓铺满通道宽度（长度超过冲刺距离），出口处有怪物把守，方便打出组合技。
- **锁门战斗房**：走进去铁栅落下，打倒房间里所有怪物（包括战斗中分裂 / 召唤出来的）才开门；中途倒下会开门重置。Boss 房也加了小怪和陷阱。

| 层 | 强制段 | 锁门战斗房 |
|---|---|---|
| 一 | 守卫室门前羽毛门廊、尖刺间的羽毛带、宝库传送带 + 羽毛带 | 守卫室 |
| 二 | 蝙蝠巢穴风道（粉末旋风）、幽灵长廊藤蔓带、机关走廊整高传送带 | 蜘蛛窝、巨魔大厅 |
| 三 | 鼠窝藤蔓带、蟹池出口传送带、传送带工坊、风洞走廊 | 鼠窝、史莱姆与精灵厅、组合试炼间、触手怪大厅 |
| 四 | 诅咒符文走廊、泡泡水道毛毯路、足枷长廊、刺猬滚道（毛毯 + 羽毛臂）、诅咒回廊 | 刑台广场、图腾大厅、手套展厅、水母女王大厅 |

前两层也加了新的组合技点：第二层蜘蛛窝门口和巨魔大厅的足枷台、幽灵长廊的羽毛臂和史莱姆、蛛丝幽灵房的蝙蝠、机关走廊的羽毛臂 + 幽灵、风道旁的泡泡鱼；第三层鼠窝的足枷台、蟹池的毛毯 + 挠脚鼠 + 分裂史莱姆、落脚点出口的泡泡鱼 + 史莱姆、触手怪大厅的足枷台 + 宝箱怪。

## 星光爆发（高风险高回报）

- 按住 L 吟唱，**不能移动**；按住 0.6 秒一档、1.2 秒二档、2 秒满蓄力（自动释放），不到 0.6 秒松开会落空
- 一档半径 36 伤害 2；二档半径 52 伤害 3；满蓄力半径 72 伤害 4，怪物僵直，还能吹散粉雾、清掉藤蔓、击散小精灵、让触手怪收手
- **弱点暴露**：吟唱时 180 像素内的怪物全部冲过来，追得更快，挠痒 ×1.5
- 闷笑值超过 55%（失控）不能吟唱；吟唱中笑到失控、被抓住或受伤都会被打断；失控以下被挠痒不会打断
- 释放后冷却 6 秒（HUD 魔法图标显示秒数），落空或被打断冷却 1.5 秒

## 背包

第四层落脚点旁的储藏室宝箱里有**冒险背包**。拿到后按 **Tab / I**（手柄 L3）打开，游戏暂停：

- **物品页**：所有物品的格子（消耗品、钥匙、金币），选中显示名称、数量、说明。**E** 直接使用；选中消耗品按 **Q / R** 把它设成对应快捷键（原来在另一个键上的会交换）。HUD 背包栏会跟着显示 [Q] / [R]。
- **状态页**：闷笑值和魔力疲倦的百分比、当前阶段和效果、疲倦的闷笑加成和下一档、魔法冷却、每个增益 / 减益的效果和剩余时间（层数），以及被困住、定身、余痒等当前情况。
- 再按 Tab 翻页，状态页再按就关闭；Esc 随时关闭。
- 没拿到背包之前 Q / R 照旧：Q 薄荷糖、R 清心花露。
- **HUD 道具栏**最多显示 3 格：Q、R 绑定的道具固定在前面，其余道具在轮播窗口里每 2.5 秒滑一格（两侧有 < > 箭头和「+N」）；刚拿到的道具会立刻转到窗口里并闪一下。新道具**星光糖**（第四层宝箱）可以让星光爆发冷却立即清零，要先在背包里设到 Q 或 R。

- **命中特效**（`assets/generated/hit_fx.png`，Python 绘制）：每种怪物和陷阱挠到人时有各自的特效——羽毛扫、手指挠、果冻溅、触须蛰、泡泡破、刷毛刷、钳子夹、紫色符咒；普通攻击是刀光，暴击再叠一个金色星环。

## 表情系统

11 种状态：普通 / 开心 / 生气 / 难过 / 惊讶 / 害羞 / 战损 / 非战损憋笑 / 战损憋笑 / 失控1 / 失控2。公主全身立绘常驻屏幕左侧，离开对话后仍显示；小人、立绘和HUD头像使用同一个最终显示状态；气泡复用对应情绪符号。

受到实际伤害或闷笑值超过 55%（失控）后，本次生命永久战损，回血不会修复，复活清除。显示优先级：失控2 > 失控1 > 憋笑（按战损区分）> 战损 > 剧情表情 > 普通；死亡定格淡出。旧剧情“大笑”已迁移为“开心”。

- 事件自动触发：开箱/金钥匙/击败敌人→请求开心，读情书→请求害羞；受伤→战损，异常状态优先于这些剧情请求。
- 对话脚本逐句指定：对话文件中每句的 `emotion` 字段。
- 代码中调用：`GameState.emote("shy", 2.0)`（时长 ≤0 表示一直保持）。

**被挠时的立绘反馈**：左下角的常驻立绘会跟着抖（平静 1 像素 → 失控 2 4 像素，暴击更大）；立绘上冒出和挠痒来源对应的小特效（羽毛扫、手指、果冻、触须、泡泡……），被挠瞬间泛粉；闷笑越高，立绘下面的粉色光晕越浓；失控后旁边会飘出小字（`data/princess_reactions.json` 的 `portrait_words`：顶层是全局默认，分失控 1 / 失控 2；每种怪物也可以在 `sources.<来源键>.portrait_words` 里单独配置，写数组表示两个阶段通用，没写的用默认）；暴击时金色星环 + 白闪，组合技触发时爆开粉色心形。

笑倒 CG 和三来源组合演出里的立绘也用同一套反馈，强度按幕递进（第一幕 = 失控 1，第二幕起 = 失控 2，第三 / 四幕和组合演出的高潮更强）：每次挠公主都会抖、泛粉、出现挠她的那只怪物 / 陷阱的贴片，飘字用该来源的 `portrait_words`；切到下一幕时金色星环，组合演出三个来源一起挠时爆开心形。第三 / 四幕的横版 CG 图用轻量版：只抖动、轻轻泛粉、沿大框左右两边飘字、大框底部淡淡的光晕，不放贴片，不挡画面。

**魔法姿态**（6 种，施法时自动切换，优先于其它状态）：吟诵 / 释放 × 普通 / 战损 / 战损闷笑。

| 时机 | 未战损 | 战损（闷笑值 ≤50） | 战损（闷笑值 >50） |
|---|---|---|---|
| 按住 L 吟唱 | 吟诵 | 战损吟诵 | 战损闷笑吟诵 |
| 松开释放（原地定住约 0.5 秒） | 释放 | 战损释放 | 战损闷笑释放（立绘借用战损释放） |

- 吟诵的 8 帧跟着蓄力进度推进：0→2 秒对应第 1→8 帧，满蓄力停在第 8 帧；释放 8 帧约 0.5 秒播完，期间受到攻击会中断。
- 小人用 48×48 的魔法图集（保留原图花瓣光效，人物大小、脚底位置与行走帧一致），脚下程序画的魔法阵和星光粒子照常叠加。

- **立绘细节**：立绘以 2 倍像素密度生成（画面拉伸模式 `canvas_items`），脸部区域的眼睛、嘴、泪滴颜色会被优先保留；表格位置自动检测，重画素材只要保持表格形式即可重新运行导入脚本。
- **音效**：`tools/art/gen_sfx.py` 合成果冻挠痒声（4 种）以及吐丝、喷粉、刷子、抓取、吟唱、星光爆发、夹钳、藤蔓、风、传送带、宝箱怪、精灵铃声、分裂、组合技提示音、暴击（水中果冻升调）、水液、泡泡、刺猬滚动、足枷、图腾、符文，输出到 `assets/generated/sfx/`。
- **CG / 组合演出**：`tools/build/gen_cgs.py` 生成笑倒 CG 总文件 `data/cgs.json`（台词和演绎都在脚本里）；`tools/build/gen_combo_scenes.py` 生成三来源组合演出 `data/combo_scenes.json`。
- **扩展美术**：`tools/art/gen_expansion.py` 生成魔法阵、星光爆发、魔法图标、小精灵、触手怪、粉色史莱姆、藤蔓、风扇、传送带、暗墙裂缝、武器架、状态图标、疲倦水液、第四层怪物与陷阱、命中特效与粒子、星光糖与背包图标等占位图。
- **其它像素美术**：`tools/art/gen_misc.py` 另外生成第二层机关占位图（`new_props.png`、`grab_hand.png`、`feather_brush.png`）；`tools/art/gen_misc.py` 生成表情气泡、道具、机关、墙体拼接图集（`gen_princess.py` / `gen_portraits.py` 是最初程序绘制的版本，现在只输出 `*_procedural.png` 备用）。
