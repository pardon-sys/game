# 公主地牢冒险

Godot 4.7 · 2D 俯视角像素游戏。粉发蓝眼、头戴金色小皇冠的公主被关进地牢，需要一路解谜、战斗逃出去。

## 操作

| 按键 | 手柄 | 作用 |
| --- | --- | --- |
| WASD / 方向键 | 左摇杆 / 十字键 | 8 方向移动 |
| E | A | 交互（开箱、开门、拉杆、点火把、读石碑/信）/ 推进对话 |
| J / 鼠标左键 | X | 挥动权杖攻击（可打碎木桶、武器架，砍断藤蔓） |
| L / 鼠标右键（按住） | LB | 星光爆发：按住吟唱、松开释放（第三层学会） |
| K / Shift | B / RB | 冲刺（短暂无敌，可穿过尖刺、躲开挠痒） |
| Q | Y | 使用 Q 键绑定的物品（默认薄荷糖：闷笑值 -27%） |
| R | Select | 使用 R 键绑定的物品（默认清心花露：清除全部疲倦印记，Boss 掉落） |
| Tab / I | L3 | 打开背包（第四层储藏室获得；打开时暂停）：查看物品、改 Q / R 绑定、查看状态 |
| Esc | Start | 暂停菜单（继续 / 重新开始 / 退出） |

## 关卡流程

- **第一层**：牢房（拉杆开牢门）→ 火把走廊（点亮火把）→ 守卫室（史莱姆、铜钥匙宝箱；旁边的**兵器库**有武器架和心）→ 储藏室（木桶）→ 书房（骑士的情书、拉杆开铁栅；点亮角落的火把会照出**暗墙**，推开是秘密储物间）→ 尖刺走廊（冲刺穿越，铜锁门）→ 宝库（金钥匙）→ 金锁大门 → 出口楼梯。走廊南侧还有**拉杆谜题间**（先拉外面的，再拉里面的）。
- **第二层**：落脚点 → 蝙蝠巢穴（羽毛蝙蝠、痒痒粉喷口；东边**喷口回廊**通往**蛛丝幽灵房**）→ 幽灵长廊（点火把让痒痒幽灵显形）→ 蜘蛛窝（吐丝减速、多足连挠）→ 机关走廊（旋转羽毛刷、压力板 + 机关手；北侧**休息室**）→ 巨魔大厅（小 Boss 挠痒巨魔，掉落金钥匙）→ 出口楼梯。
- **第三层·痒痒工坊**：落脚点（学会星光爆发，拿小精灵练手）→ 鼠窝（挠脚鼠 + 藤蔓）→ 藤蔓迷道 → 蟹池（钳钳蟹 + 传送带）→ 传送带工坊（西侧可选的**组合试炼间**）→ 风洞走廊（风扇把人吹进粉雾和刷子，东头拉杆关风扇；东侧宝物间里有一只宝箱怪）→ 史莱姆与精灵厅 → 触手怪大厅（Boss）→ 出口楼梯（第三章完）。
- **第四层·魔力回廊**（更难：检查点只有 4 个，每段强制段都对应组合技）：落脚点（石碑讲暴击、魔力疲倦、疲倦爆发、三重组合）→ **储藏室**（宝箱里是冒险背包）→ 水母池 → 诅咒符文走廊 → 泡泡水道（中间只有一条黏黏毛毯路）→ 足枷长廊（毛毯、整宽足枷台、符文、墙上羽毛臂，出口一对幽灵手套）→ **刑台广场**（战斗房：足枷台阵 + 老鼠、螃蟹、蜘蛛、史莱姆、小精灵、手套）→ 刺猬滚道（整高毛毯 + 顶墙羽毛臂，凹槽可躲；南边**诅咒回廊**通往可选的**手套展厅**战斗房）→ 图腾大厅（战斗房）→ 魔力水母女王大厅（Boss）→ 出口楼梯（第四章完，通往第五层）。
- **第五层·机关迷城**（陷阱为主、怪物为辅，约第四层的 2 倍大，6 个检查点）：开场过场（镜头扫过机关）→ 落笼回廊（看影子躲落笼、冲刺跳过绊线、小工匠踩机关）→ 束缚工坊（连锁①：倒吊绳套 → 传送带 → 弹弹床 → 举手铐柱 → 弹弹床 → 挠痒衣柜；仰卧刑床 + 肚脐羽毛钻 + 长舌蛙）→ 西边的**滑梯坡道**（连锁⑥：滑梯 → 俯卧刑凳 → 滑梯 → 痒痒坐垫 → 滑梯 → 仰卧刑床，尽头有宝箱）→ 腿刑长廊（连锁②：夹腿枷台 → 泥沼 → 吸痒漩涡里的单腿吊环）→ **小精灵温室**（战斗房）→ 转轮工坊（连锁③）→ 泥沼地窖（连锁④：泥沼 → 风扇 → 吊环 → 衣柜）→ **工匠车间**（战斗房：一群小工匠、长靴、绑腿）→ 最终连锁长廊（连锁⑤：倒吊 → 夹腿 → 泥沼 → 吊环）→ 准备间（自动获得被动技能「挣脱强化」）→ **无解陷阱房**（满屋三来源组合：门口一簇簇组合用传送带一个接一个往下送，下半部分是一圈首尾相接的滑梯、四个拐角各一个束缚陷阱，一进去就连着触发组合；进去出不来，第 4 次倒下复活后播结局过场，公主昏迷后被一个黑影带走——第五章完，未完待续）。这一层的空地都铺满了陷阱（检查点房间除外）。
  每段连锁都留着一条不碰束缚机关的路，看准时机就能躲开；可一旦中了第一个，放开后就会被传送带、弹弹床、风扇、漩涡一路送进下一个。
  五个大房间（束缚工坊、滑梯坡道、腿刑长廊、转轮工坊、泥沼地窖）是 2 格宽走廊的迷宫：主路上必经一串「连锁小厅」，每间 2~3 组三来源组合，躲不开——中了第一个，放开后传送带把人送到下一个小厅的束缚陷阱旁边，一个接一个；死胡同尽头有宝箱，主路上零散放着单个陷阱和怪物。
  所有束缚陷阱（包括足枷台）都比本体多一格触发范围：走到相邻格就被拉过去扣住（隔着墙不会）。石碑不会挡在传送带 / 滑梯 / 风扇的通道和束缚陷阱的拉人范围上。检查点是地上的粉色魔法阵 + 漂浮的水晶：当前复活点的水晶发光旋转，其它的变暗。第五章结束画面按 E 继续，进入第六层。
- **第六层·地下小镇**（可以随时回来的大地图，没有敌人；四张地图用楼梯上下）：
  - **营地地牢**（开场）：公主在保卫队营地下面的地牢里被痒醒——仰躺在刑床上、脚扣在足枷里、腿被夹腿枷台夹着。保卫队队长指责她独自跑到外面去，公主说自己什么都不知道。**关键选择**：老实解释 / 顶嘴反驳 / 笑着求饶。队长不信，把她换到挠痒坐垫 + 举手铐柱上，叫队员一起挠（小剧场，台词随选择不同），直到一位**蓝色调的公主**出来叫停。之后自由活动。
  - **集市层**：集贸市场（摊位和市场监督，用金币买东西）、篝火派对广场（篝火回满生命、清空闷笑；篝火派对的主人会教你跳舞）、居民区、**存档点**（小镇里唯一的一个）、封住的地牢入口。
  - **营地层**：保卫队营地（帐篷、哨塔、队长的指挥帐篷）、训练场（训练小游戏以后接入，现在显示「还在整修」）。
  - **矿道层**：矿车、矿工、封住的深处大门（以后通往新的地牢）。
  - 15 个会溜达的居民（友军）+ 4 个关键人物（保卫队队长、市场监督、篝火派对的主人、蓝色的公主），走近按 E 对话。

## 闷笑值

怪物除了攻击（扣血），还会**挠痒**（累积闷笑值，HUD 心形下方的粉色条）。史莱姆优先选择挠痒：概率75%，冷却0.6秒；普通攻击概率25%，冷却1.2秒。

阶段和恢复量都按**上限的百分比**算（上限现在是 150，以后提高上限只改 `LaughMeter.max_value`）；怪物的挠痒量是固定值，所以上限越高越耐挠。HUD 两条状态条右边显示百分比。

- 超过 35%：移动变慢，时不时发笑
- 超过 55%：失控状态1，无法行动，持续大笑；**连按 J / E 挣扎**（每次 -2%）
- 超过 70%：失控状态2，行动限制相同；降回 70% 以下切回状态1
- 满 100%：笑到脱力，扣半颗心，回落到 70%
- 2 秒没有被攻击后每秒下降 6.7%；薄荷糖立即 -27%；骑士帮忙 -17%
- 被抓住（巨魔、机关手）：不能行动，连按 J / E 挣脱，同时降低闷笑值；挣脱后巨魔会僵直一会儿
- 第二层的怪物更爱挠痒：蝙蝠 90%、幽灵 100%、蜘蛛与巨魔 85%；挠痒时有合成的果冻"啵叽"声
- 第三层：挠脚鼠 90%（公主动不了时挠痒加倍）、钳钳蟹 85%（夹住定身 1 秒）、分裂史莱姆 85%、宝箱怪 90%、小精灵群 100%、触手怪 90%
- **部位与敏感值**：每一下挠痒都会落在一个部位（脚心、腋下、腰、脖子、大腿、肚子、屁股、胸），各部位敏感倍率不同（脚心 ×1.2、胸 ×1.2、腋下 ×1.15、肚子 ×1.1……）；越笑越敏感（憋笑 ×1.05 → 失控 2 ×1.15）、同一部位连续被挠越来越敏感（每下 +3%，最多 +30%）、战损后 ×1.1。被束缚陷阱困住时露出的部位挠起来更痒（×1.3 / ×1.5，头上跳「弱点！」）。立绘上的特效贴片出现在被挠的部位，飘字也是那个部位的台词。每个部位还有**专属挠痒特效**（脚心：蜷脚趾 + 小星星；腋下：螺旋；腰：扭动线；脖子：发抖线；大腿：晃动弧；肚子：一圈圈波纹；屁股：弹跳小星星；胸：被戳的凹痕 + 小音符），公主身上和立绘部位各播一份，挠到弱点时放大变亮。部位和数值都在 `data/actors/princess_ticklish.json`，每种怪物 / 陷阱挠哪些部位在 `data/tickle_zones.json`。
- 第四层：魔力水母（疲倦 ×3，被打散留水液）、泡泡鱼（泡泡牢笼，连按 5 次戳破）、幽灵手套（成对，两只凑齐必暴击 + 搭档补挠，只挠不打）、刷刷刺猬（同行 / 同列时滚过来，必暴击 + 击退，滚动时剑打不动，撞墙会晕）、魔力水母女王（召唤水母、留水液、半血后魔力雨）

## 特殊挠痒（暴击）

怪物的每次挠痒（包括抓住后的持续挠痒）都可能是**特殊挠痒**：闷笑值 ×2，魔力疲倦 ×2（按暴击后的量再乘），播放水里果冻抖动的升调音效，公主头上跳金色「暴击！」、镜头轻震，公主说该怪物专属的暴击台词（`princess_reactions.json` 各来源的 `special`）。

- 暴击率：普通怪 12%、Boss 20%（水母 25%、水母女王 35%），在 `data/monsters/*.tres` 的 `special_chance` 调；「狂热」增益 +20%
- 必暴击：幽灵手套成对时、刷刷刺猬滚中时、足枷台超时的最后一下、组合技的「下次必暴击」

## 魔力疲倦

HUD 闷笑条下方紫色的「魔力」条（上限 500，刻度 40% / 60% / 80%，超过 90% 闪烁并提醒）。

- 被挠痒时积累：挠痒量的一半；暴击时为两倍；魔力水母的挠痒再 ×3；诅咒符文（+4%）、魔力雨（每秒 +0.6%）、部分组合技（+2% ~ +10%）按百分比直接加
- **不会消散**：不随时间下降，复活不清零，跨层保留（重新开始游戏才清零）
- 闷笑积累加成（先缓后升）：20% → +1%、40% → +5%、60% → +10%、80% → +30%、100% → +50%
- **疲倦爆发**：满 500 自动释放一次星光爆发（战损释放姿势，满蓄力的一半：半径 72、伤害 2，不僵直），疲倦清零；原地留下**疲倦水液**（30 秒，怪物踩进去获得「力量」）；公主获得一层永久的**疲倦印记**（闷笑积累 +1%）。爆发台词在 `data/princess_fatigue.json`
- **清心花露**（默认 R 键）：清除全部疲倦印记；只有 Boss 掉落（挠痒巨魔、痒痒触手怪、魔力水母女王）

## 增益 / 减益

所有角色（`Actor`）都能带状态，定义在 `data/buffs.json`。公主的状态显示在 HUD 心形右边（限时的快结束时闪烁，印记显示层数）；怪物有增益时头顶有小图标。

| 状态 | 效果 | 来源 |
|---|---|---|
| 力量（增益） | 挠痒冷却 ×0.6 | 疲倦水液、组合技 |
| 狂热（增益） | 暴击率 +20%，挠痒冷却 ×0.8 | 狂热图腾光环、精灵起哄 |
| 易痒诅咒 | 闷笑积累 +30% | 诅咒符文、组合技 |
| 黏黏 | 移动速度 ×0.4 | 黏黏毛毯、组合技 |
| 封魔 | 不能吟唱 | 无形蛛网 |
| 疲倦印记（永久，可叠层） | 每层闷笑积累 +1% | 疲倦爆发 |
| 抬起 | 被举到半空，动不了、挣扎无效、一直被挠 | 三来源组合 |
| 晕头转向 | 方向键颠倒 | 三来源组合 |
| 全场暴击 | 受到的每一下挠痒都算暴击 | 三来源组合 |

第四层陷阱：**狂热图腾**（光环内怪物狂热；剑敲三下或任意档星光爆发打碎）、**诅咒符文**（易痒 10 秒 + 疲倦 4%）、**足枷台**（锁住 3 秒，连按 6 次挣脱，超时最后一下必暴击）、**黏黏毛毯**（多格；站着不动 1 秒被黏住）、**伸缩羽毛臂**（墙面，红灯预警后横扫前方两格，定身 + 挠痒 8）。传送带比以前更快（默认 70）。

**强制位移陷阱**（把人送进足枷台、藤蔓这类固定陷阱）：
- **吸痒漩涡**：半径 3 格内一直往中心吸，越靠近越快；外圈走得出去，靠近中心只能**冲刺挣开**。中心通常是足枷台。
- **弹弹床**：踩上去沿箭头方向弹出几格，飞行中不能操作、不能冲刺，飞过的陷阱不生效，落点照常触发（常常是足枷台或机关手下方）。
- **滑溜肥皂地板**：在上面一动就沿移动方向一直滑，直到撞墙、离开地板，或滑到足枷台 / 藤蔓 / 毛毯上才停；滑行中不能换方向。

**怪物巢穴**（鼠洞、精灵花、史莱姆池、水母卵、宝箱堆）：公主在附近时每 6 秒生成一只对应的怪物（同时最多 2 只），宝箱堆生成的宝箱怪是醒着的。血 4，剑可以打，**满蓄力星光爆发直接打碎**（低档扣 2）。
- **吟唱联动**：在巢穴附近吟唱（弱点暴露），巢穴会额外生成怪物，越来越快（0.4 秒起，满蓄力大约 6 只），而且一出来就冲向公主；吟唱结束 3 秒后没被打倒的额外怪物缩回巢穴。
- **拖进巢穴**：公主失控时，贴身的巢穴怪物会抓住她往巢穴里拖（每多一只一起拖就更快），连按 J / E 10 次挣脱；被拖进去就会笑倒，播一段这种巢穴的过场 CG，然后在检查点复活。
- 战斗房里的巢穴也要打碎才算清场。

**新机制的介绍石碑**：每种新机制第一次出现之前都有一块石碑介绍它——第二层幽灵长廊的史莱姆池前（怪物巢穴：生成、打碎、吟唱联动、拖进巢穴）、机关走廊东口（弹弹床）、巨魔大厅门前（吸痒漩涡 + 巨魔召唤蝙蝠），第三层落脚点去鼠窝的路上（滑溜肥皂地板）。

**Boss 开局召唤**：痒痒触手怪一开战就召唤小精灵群，挠痒巨魔一开战就召唤 2 只羽毛蝙蝠，之后定时补充；Boss 倒下时召唤的小怪一起散掉。

## 笑倒 CG

被挠到笑倒时，不会直接复活，而是先播一段笑倒 CG：画面切到一个小舞台，挠倒公主的那只怪物登场继续挠，配合对话、立绘切换和镜头，最后在检查点醒来。

- **算笑倒**：闷笑值满把最后一点血笑没；或者倒下时正在失控（闷笑值 >55%）、正被抓住、2 秒内刚被挠过（最后一下是普通攻击也算）。不在挠痒状态时被打死不播 CG，照旧复活。
- 16 种怪物各有一段专属 CG（按最后挠她的怪物选；来源不明时按打倒她的怪物），陷阱致死播通用 CG。
- 怪物 CG 分三幕：失控 1 立绘 → 失控 2 立绘 → **CG 图**（剧情最多）。有两张 CG 图的怪物（泡泡鱼、魔力水母女王）多一幕：第三幕第一张图、第四幕第二张图。CG 图阶段立绘框变成对话框上方的横版大框（保持原图比例），并随挠痒抖动；右边的小舞台继续演。
- **最后一幕：魔力爆发**（所有笑倒 CG、巢穴过场和三来源组合演出都有，有第四幕的接在第四幕后面）：被挠到魔力疲倦满了 → 白光一闪、星光爆发和魔力释放的水声，怪物被震开，立绘换成**战损魔力释放** → 公主说出释放后全身好舒服 → 怪物又回来了，释放后身体变得更敏感，痒得更厉害 → 笑到力竭。台词每段单独写，在 `tools/build/burst_lines.py`；以后放了 `assets/cg/portraits/fatigue_burst.png` 就换成正式立绘。
- 每次笑倒都会播；看过的 CG 画面角落会提示「Esc 跳过」，第一次看不能跳过。
- **被拖进巢穴**：五种巢穴各有一段三幕过场（被拖进巢穴口 → 巢穴里一群一起挠 → CG 图，第三幕大批同类怪物从四周涌上来一起挠），写在单独的文件 `data/nest_cgs.json`（由 `tools/build/gen_nest_cgs.py` 生成，台词在脚本里改）。第三幕的 CG 图现在用失控 2 占位；把图放进 `assets/cg/portraits/nest_<种类>_3.png`（如 `nest_rat_hole_3.png`）后重新运行 `gen_nest_cgs.py` 就会换成横版大框。
- 所有 CG 写在一个文件 `data/cgs.json` 里（对话、演员、演绎指令、立绘都按步骤写），格式说明在文件开头和架构文档里。
- **立绘接口**：前两幕的 CG 立绘现在用失控 1 / 失控 2 占位，正式素材按 id 命名放进 `assets/cg/portraits/`（如 `slime_1.png`）就会自动替换，见该目录的 README。
- **CG 图**：手绘原图放在 `assets/generated/CG/<来源键>.png`（两张图时命名 `<来源键>_1.png` / `<来源键>_2.png`，扩展名大小写都行），运行 `python tools/art/import_cg.py [--preview]` 像素化成 `assets/cg/portraits/<来源键>_3.png`（第二张为 `_4.png`；保持比例、高 360 = 显示 180 的 2 倍密度）。然后运行 `python tools/build/gen_cgs.py` 重新生成 `data/cgs.json`：CG 图存在时自动用横版大框，台词也在这个脚本里改。

## 第五层的新陷阱和怪物

**束缚陷阱**（困住时露出部位，连按 J / E 挣脱）：倒吊绳套（倒吊，脚心 ×1.5）、举手铐柱（双手举过头顶，腋下 ×1.5）、夹腿枷台（夹住大腿，大腿 ×1.5）、挠痒衣柜（墙边，拉进柜里只露出脚，脚心 ×1.3）、痒痒泥沼（越陷越慢，陷住后脚心 + 大腿 ×1.3）、单腿吊环（吊起一条腿，脚心 + 大腿 ×1.3）、痒痒长靴（自己套上脚：走不快、不能冲刺，靴里羽毛挠脚心）、羽毛绑腿（双腿缠住只能蹦，连按攻击键挣开）。

**配套挠痒机关**（和旁边的束缚陷阱连着，有人被困时专挠露出的部位；没人被困时，站上转轮 / 走到逗弄器旁边 / 走进喷口下方，它们也会自己挠）：羽毛逗弄器（专挠露出的部位；有羽毛 / 刷子 / 史莱姆 / 小触手版）、痒痒转轮（羽毛、刷子、手轮流换面）、羽毛雨喷口（3×3 落羽毛雨，也可以被压力板 / 绊线触发、对准公主）。

**触发类**：落笼（不对准的落笼平时地上就有淡淡的影子，预警时变深变大；史莱姆 / 触手笼会放出真的怪物）、绊线（公主或怪物碰到就让连着的机关对准公主发动，冲刺可以跳过）、怪物也能踩的压力板。被压力板 / 绊线连着的落笼、喷口、机关手，自己走到它们下面也会触发。

**被困时的台词**：被束缚类陷阱困住后，公主说的是正在被挠的反应（带出部位和手法），不再只是「被关住了」的陈述；落穴洞按洞里住的怪物（挠脚鼠 / 刷尾松鼠 / 史莱姆 / 小触手）各有一套。台词在 `tools/build/gen_trap_lines.py`。

**失控时的位移**：笑到失控时也会被弹弹床弹飞、在肥皂地板 / 滑梯上滑走、被张臂转盘甩出去（传送带、风扇、漩涡本来就推得动）。

**机关小工匠**：自己挠得不重，但会跑去踩压力板、碰绊线，把拉杆关掉的机关拨回来，被打一下就逃去拉拉杆。

## 关卡设计：躲不开的陷阱配合

每层都有几段"强制遭遇"，参考第三层风洞走廊（风扇把人吹进痒痒粉和旋转刷）的做法，让陷阱和怪物的配合绕不过去：

- **强制位移**：风扇风道、传送带铺满整条通道，把人送进喷口 / 旋转刷 / 机关手 / 怪物堆；关掉它们的拉杆放在危险区的另一侧。
- **窄道铺满陷阱**：羽毛陷阱、藤蔓铺满通道宽度（长度超过冲刺距离），出口处有怪物把守，方便打出组合技。

## 地图内过场动画

和笑倒 CG（另一个小舞台）不同，过场动画直接在当前地图里演：上下滑入黑框，镜头在地图上移动，公主和关卡里的机关、怪物就是演员（还可以临时生成演员，比如蒙黑的人影）。播放时机关和怪物都暂停，公主不能操作；看过的过场按 Esc 跳过。每段过场一个文件：`data/cutscenes/<楼层组>/<id>.json`（格式和 CG 的步骤一样；步骤里可以写 `talk` 打开人物对话、`theater` 播小剧场，动作 `hold` 让刑具一直扣着公主），关卡 `[level]` 段写 `intro_cutscene = <id>` 当开场，或用图例 `trigger cutscene=<id>` 走到某处触发。第五层的开场和结局都是过场。

## 对话选项与选择记忆

和人物说话时会弹出选项（上下选、E 确定；整段对话期间公主和居民都不会动）。选项有两种：**选完一路说到结束**，和**这段演完回到选项页**（「聊聊营地」「你是谁」这类可以一个个问的）。条件不满足的选项不显示，有的选项只能选一次。
对话里还能演一段**地图内过场**（比如队长带你看营地）或**小剧场**（CG 那样的小舞台，比如篝火派对的舞）。关键人物说话时，对话框右边显示对方的半身像素立绘。
**选择记忆**：关键选择会记下来（比如开场的态度 `f6_attitude`），之后其他人物的打招呼、台词和可选的选项都会跟着变。比如顶嘴之后队员会学你喊「我可是公主」，市场监督会多一个「队长说我坏话了吗？」的选项；求饶之后全镇都叫你「爱笑的公主」。第六层有 16 个人物会对开场的选择有反馈。

## 背包

第四层落脚点旁的储藏室宝箱里有**冒险背包**。拿到后按 **Tab / I**（手柄 L3）打开，游戏暂停：

- **物品页**：所有物品的格子（消耗品、钥匙、金币），选中显示名称、数量、说明。**E** 直接使用；选中消耗品按 **Q / R** 把它设成对应快捷键（原来在另一个键上的会交换）。HUD 背包栏会跟着显示 [Q] / [R]。
- **被动技能页**：学会的被动技能（图标、等级），选中显示当前等级和下一级的效果。被动技能写在 `data/passives/passives.json`，支持升级。目前有「挣脱强化」（第五层最后一关前自动获得：连按 J / E 挣扎时闷笑值多降 30%，满级 75%）。
- **状态页**：闷笑值和魔力疲倦的百分比、全身和各部位的敏感度、当前阶段和效果、疲倦的闷笑加成和下一档、魔法冷却、每个增益 / 减益的效果和剩余时间（层数），以及被困住、定身、余痒等当前情况。
- **CG 图鉴页**：笑倒 CG、巢穴过场、三来源组合演出的列表，看过的可以按 E 重看（测试模式下全部可看）。上下选择，左右翻页。
- 按 Tab 依次翻到物品 → 被动技能 → 状态 → CG 图鉴，最后一页再按就关闭；Esc 随时关闭。
- 没拿到背包之前 Q / R 照旧：Q 薄荷糖、R 清心花露。
- **HUD 道具栏**最多显示 3 格：Q、R 绑定的道具固定在前面，其余道具在轮播窗口里每 2.5 秒滑一格（两侧有 < > 箭头和「+N」）；刚拿到的道具会立刻转到窗口里并闪一下。新道具**星光糖**（第四层宝箱）可以让星光爆发冷却立即清零，要先在背包里设到 Q 或 R。

## 攻击特效

- **命中特效**（`assets/generated/hit_fx.png`，Python 绘制）：每种怪物和陷阱挠到人时有各自的特效——羽毛扫、手指挠、果冻溅、触须蛰、泡泡破、刷毛刷、钳子夹、紫色符咒、吸盘、毛虫小脚；普通攻击是刀光，暴击再叠一个金色星环。另外每个部位有专属特效（`assets/generated/zone_fx.png`，`tools/art/gen_zone_art.py`），叠在来源特效上。

## 表情系统

11 种状态：普通 / 开心 / 生气 / 难过 / 惊讶 / 害羞 / 战损 / 非战损憋笑 / 战损憋笑 / 失控1 / 失控2。公主全身立绘常驻屏幕左侧，离开对话后仍显示；小人、立绘和HUD头像使用同一个最终显示状态；气泡复用对应情绪符号。

受到实际伤害或闷笑值超过 55%（失控）后，本次生命永久战损，回血不会修复，复活清除。显示优先级：失控2 > 失控1 > 憋笑（按战损区分）> 战损 > 剧情表情 > 普通；死亡定格淡出。旧剧情“大笑”已迁移为“开心”。

- 事件自动触发：开箱/金钥匙/击败敌人→请求开心，读情书→请求害羞；受伤→战损，异常状态优先于这些剧情请求。
- 对话脚本逐句指定：对话文件中每句的 `emotion` 字段。
- 代码中调用：`GameState.emote("shy", 2.0)`（时长 ≤0 表示一直保持）。

**被挠时的立绘反馈**：闷笑值到憋笑以上，立绘轮廓外会发出一圈柔和的粉色光晕（Godot shader 沿人物轮廓画，不是方框），越笑越亮，失控时轻轻呼吸。左下角的常驻立绘会跟着抖（平静 1 像素 → 失控 2 4 像素，暴击更大）；立绘上冒出和挠痒来源对应的小特效（羽毛扫、手指、果冻、触须、泡泡……），被挠瞬间泛粉；失控后旁边会飘出小字（`data/princess_reactions.json` 的 `portrait_words`：顶层是全局默认，分失控 1 / 失控 2；每种怪物也可以在 `sources.<来源键>.portrait_words` 里单独配置，写数组表示两个阶段通用，没写的用默认）；暴击时金色星环 + 白闪，组合技触发时爆开粉色心形。

笑倒 CG 和三来源组合演出里的立绘也用同一套反馈，强度按幕递进（第一幕 = 失控 1，第二幕起 = 失控 2，第三 / 四幕和组合演出的高潮更强）：每次挠公主都会抖、泛粉、出现挠她的那只怪物 / 陷阱的贴片，飘字用该来源的 `portrait_words`；切到下一幕时金色星环，组合演出三个来源一起挠时爆开心形。第三 / 四幕的横版 CG 图用轻量版：抖动、轻轻泛粉、沿大框左右两边飘字，挠痒来源的贴片放在图的四周（不挡画面中心），光晕改成大框内侧一圈粉色晕光。组合演出里立绘跟着舞台上公主的姿势：开始是失控 1，第三个来源加入后变成失控 2。

**魔法姿态**（6 种，施法时自动切换，优先于其它状态）：吟诵 / 释放 × 普通 / 战损 / 战损闷笑。

| 时机 | 未战损 | 战损（闷笑值 ≤50） | 战损（闷笑值 >50） |
|---|---|---|---|
| 按住 L 吟唱 | 吟诵 | 战损吟诵 | 战损闷笑吟诵（憋笑以上不管有没有战损都用这张，吟唱中闷笑变化立即切换） |
| 松开释放（原地定住约 0.5 秒） | 释放 | 战损释放 | 战损闷笑释放（立绘借用战损释放） |

- 吟诵的 8 帧跟着蓄力进度推进：0→2 秒对应第 1→8 帧，满蓄力停在第 8 帧；释放 8 帧约 0.5 秒播完，期间受到攻击会中断。
- 小人用 48×48 的魔法图集（保留原图花瓣光效，人物大小、脚底位置与行走帧一致），脚下程序画的魔法阵和星光粒子照常叠加。

  - `common.json`：复活、上锁提示等通用对话。
  - `<楼层组>/signs.json`、`story.json`：本层的石碑和剧情对话。
  - `<楼层组>/<人物>.json`：**每个人物一个文件**，带选项、条件、演绎（格式见 docs/ARCHITECTURE.md 的「人物对话」）。人物表（名字、行走图、半身立绘）在 `data/actors/npcs.json`。
  - 第六层的对话、过场、小剧场由 `tools/build/gen_floor06.py` 生成；改完运行 `python tools/build/check_dialogues.py` 检查节点跳转、引用的过场 / 小剧场、选择变量有没有人写。
- **过场 / 小剧场**：`data/cutscenes/<楼层组>/<id>.json`（地图内过场）、`data/theater/<楼层组>/<id>.json`（小剧场，CG 舞台格式，演员可以写 `npc:<人物>`）。
- **商店 / 训练**：商品表 `data/shop/market.json`（物品、金币价格、库存）；训练项目 `data/training/trainings.json`，小游戏场景以后放 `scenes/training/<训练 id>.tscn`（接口 `TrainingDB`）。
- **地图**：编辑 `levels/floor_01/map.txt`（`[legend]` 定义字符含义，`[map]` 为地图），然后重新构建：
  ```
  Godot --headless --path . --script res://tools/build/build_level.gd -- floor=floor_01
  Godot --headless --path . --script res://tools/build/build_level.gd -- floor=floor_06_upper   # 第六层的一张地图
  ```
  也可以直接在编辑器里打开 `levels/floor_01/floor.tscn` 修改（注意重新构建会覆盖编辑器里的改动）。
- **公主精灵与立绘**：保留原始 `princess2.png` / `princess3.png` / `portraits2.png` / `portraits3.png`。`tools/art/import_princess2.py` 去除白底、表格和标签，输出 `princess.png`（32×32，11行×16列）、`portraits.png`（113×152每格）和 `portrait_heads.png`（32×32每格）。图集顺序由 `data/actors/princess_visuals.json` 统一定义，运行时与导入器共同读取。
  - 每行依次为下、左、右、上，每方向4帧；左右使用独立素材。失控2原图每方向只有两幅宽姿势，按1、2、1、2重复为四帧，完整保留横卧身体。
  - 攻击/冲刺复用状态帧与既有刀光/残影；受击闪白，死亡定格淡出，没有新增绘画素材。
  - 立绘和头像按姿势取景，预览包含状态、方向和帧编号。
  ```sh
  conda activate test_for_master
  python tools/art/import_princess2.py --preview
  ```
  预览输出到 `tools/.cache/p2/`；四张原图不会被覆盖。
  - **魔法姿态**：源图放在 `assets/generated/additional_princess/`（`princess4.png` 普通版、`princess5.png` 战损版 + 战损闷笑版，每张表 = 蓄力吟诵 8 帧 + 魔法爆发 8 帧 × 下/左/右/上；`portraits4.png` 吟诵、释放，`portraits5.png` 战损吟诵、战损闷笑吟诵、战损释放）。同一个导入脚本输出 `princess_magic.png`（48×48，6 行 × 32 列），立绘和头像追加在 `portraits.png` / `portrait_heads.png` 末尾。
  - 表格按表头的帧编号自动定位；吟诵、释放立绘的取景在 `princess_visuals.json` 的 `portrait_crops` 里调。这个文件夹有 `.gdignore`，Godot 不导入源图（其中两张其实是 JPEG 数据）。
  - 预览：`magic48.png`（全部魔法帧）、`grid_princess4.png` / `grid_princess5.png`（切格框）。
- **受挠台词**：全部在 `data/princess_reactions.json`（另有 `combos` 组合技台词、`magic` 魔法台词）。`lines` 是通用台词（平静、憋笑、失控1、失控2、被抓）；`sources` 按怪物/陷阱分别写：第一次被它挠痒时的剧情对话 `first_encounter`、各阶段专属台词（没写的阶段自动用通用台词）、怪物头顶的回嘴 `taunts`。台词出现在常驻立绘旁，不暂停战斗；同档 1.6 秒内不刷新，跨档立即更新，2.4 秒后消失。
- **公主笑声**：轻笑使用 cicifyre 的CC0素材；闷笑值超过 55%（失控）时使用 moxobna 的CC0自然笑声，去除长停顿、交叉淡化接缝后连续循环。专用单通道避免叠音，降回失控以下、死亡或暂停停止，恢复游戏后仍处于失控则继续。来源与处理记录见两处音频目录中的 `License.txt`。
  - `assets/third_party/cicifyre_voice/`：轻笑及旧单次大笑素材。
  - `assets/third_party/moxobna_voice/laugh_loop.wav`：当前使用的连续大笑；可用 `tools/art/build_laugh_loop.py` 从源文件重新制作。
- **立绘细节**：立绘以 2 倍像素密度生成（画面拉伸模式 `canvas_items`），脸部区域的眼睛、嘴、泪滴颜色会被优先保留；表格位置自动检测，重画素材只要保持表格形式即可重新运行导入脚本。
- **音效**：`tools/art/gen_sfx.py` 合成果冻挠痒声（4 种）以及吐丝、喷粉、刷子、抓取、吟唱、星光爆发、夹钳、藤蔓、风、传送带、宝箱怪、精灵铃声、分裂、组合技提示音、暴击（水中果冻升调）、水液、泡泡、刺猬滚动、足枷、图腾、符文，输出到 `assets/generated/sfx/`。
- **CG / 组合演出**：`tools/build/gen_cgs.py` 生成笑倒 CG 总文件 `data/cgs.json`（台词和演绎都在脚本里）；`tools/build/gen_combo_scenes.py` 生成三来源组合演出 `data/combo_scenes.json`。
- **扩展美术**：`tools/art/gen_expansion.py` 生成魔法阵、星光爆发、魔法图标、小精灵、触手怪、粉色史莱姆、藤蔓、风扇、传送带、暗墙裂缝、武器架、状态图标、疲倦水液、第四层怪物与陷阱、命中特效与粒子、星光糖与背包图标等占位图。
- **新部位美术**：`tools/art/gen_zone_art.py` 生成部位专属特效、仰卧刑床 / 坐垫 / 俯卧刑凳 / 落穴洞 / 张臂转盘 / 羽毛背心 / 滑梯 / 掸子墙，以及长舌蛙、刷尾松鼠、章鱼宝宝、毛毛虫、藤壶贝。
- **其它像素美术**：`tools/art/gen_misc.py` 另外生成第二层机关占位图（`new_props.png`、`grab_hand.png`、`feather_brush.png`）；`tools/art/gen_misc.py` 生成表情气泡、道具、机关、墙体拼接图集（`gen_princess.py` / `gen_portraits.py` 是最初程序绘制的版本，现在只输出 `*_procedural.png` 备用）。

## 测试模式

项目根目录的 `dev_config.json`：把 `"dev_mode"` 改成 `true` 打开，`false` 关闭。打开后：

- **跳关**：Esc 暂停菜单多一项「测试：跳关」，可以跳到第一~五层的起点、「第五层·准备间」（直接测无解房间）、第六层开场，或者开场后的地下小镇 / 保卫队营地。跳过去时补齐前面各层的流程奖励：第三层的魔法、第四层的背包和星光糖、第五层准备间的挣脱强化。跳关点和奖励都在这个文件里改。
- **CG 快速预览**：背包「CG 图鉴」页所有 CG 都能直接播放；没拿到背包也能按 Tab 打开背包。
